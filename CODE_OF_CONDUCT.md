# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(version 2.1).

In short: be respectful and constructive. Harassment, discrimination, and
personal attacks are not tolerated. We want participation in Custos — issues,
pull requests, and discussions — to be a welcoming experience for everyone.

Report unacceptable behavior privately to the maintainers via a
[GitHub security advisory](https://github.com/NationalHeritageAcademies/custos/security/advisories/new)
or by contacting a repository administrator. Reports will be handled
confidentially.
