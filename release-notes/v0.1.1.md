Custos 0.1.1 — hardening and bug fixes

A patch release focused on privacy, robustness, and a round of UI fixes found in
a full click-through. Signed and notarized builds are attached for macOS
(universal), Windows, and Linux.

## Privacy & security

- **No more third-party font requests.** Inter and JetBrains Mono are now bundled
  with the app instead of fetched from Google Fonts — the last outbound call the
  app made on its own. A strict Content-Security-Policy now backs this up.

## Reliability

- **The local web host no longer crashes** when a saved connection can't
  authenticate (for example, an Azure SQL / NTLM connection whose password isn't
  in memory after a restart). It now returns a clear "re-enter your password"
  message and keeps running.
- **Large MySQL results stream and stop at the row limit.** A capped `SELECT` no
  longer pulls an entire huge table into memory before truncating — it stops
  fetching once the limit is reached, so memory stays bounded regardless of table
  size.

## Interface fixes

- The **Light / Dark / System** selector now highlights the mode that's actually
  active (previously it always showed "Light").
- Clicking a table **opens a preview in a new tab** instead of overwriting the
  query you're working on.
- Fixed an internal error that occurred when clicking a table, switching editor
  tabs, or reopening a query from history.
- The status bar now shows the **real connection count and cursor position**, and
  the results footer reports the fetched row count accurately (with a clear
  "row limit reached" note when a query is capped).
- **Esc** now closes open dialogs.

## Release pipeline

- Tagged releases now build, sign, and **publish automatically** from committed
  release notes.
