Custos 0.1.0 — first public release

The first release of Custos, an open-source desktop database client for
Azure SQL and MySQL. Signed and notarized builds are attached for macOS
(universal), Windows, and Linux.

## Highlights

- **Two engines, one client.** Pluggable driver architecture with first-class
  Azure SQL and MySQL support, including Windows/NTLM auth for Azure SQL and
  cross-database browsing.
- **A real editor.** Monaco-powered SQL editor with multiple tabs, run-selection,
  cancel/timeout controls, and query history.
- **Results that work.** Virtualized results grid for large sets, multiple
  result-sets, client-side filter/sort, resizable columns, and CSV export.
- **Light and dark themes** from the ground up, driven by the design tokens.
- **DataGrip import.** Bring your existing connections over from a DataGrip
  `datasources.xml`.
- **Runs two ways.** Native desktop (Electron) or a local web host
  (`npm run web`) that binds to `127.0.0.1` for environments where the desktop
  shell isn't available.

## Security

- Credentials are stored in the OS keychain via Electron `safeStorage` on the
  desktop, and in memory only in the web host — never written to disk in
  plaintext.
- No telemetry; the only outbound connections are to the databases you configure.

See [SECURITY.md](https://github.com/NationalHeritageAcademies/custos/blob/main/SECURITY.md)
for the full security notes.
